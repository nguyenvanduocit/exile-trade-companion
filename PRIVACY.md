# Privacy Policy — Exile Trade Companion

Last updated: 2026-09-06

Exile Trade Companion is a browser extension for the Path of Exile trade site. It stores your bookmarks, folders and settings locally in your browser. Folder sharing sends only the folders you explicitly share to Liveblocks.

## Usage statistics

To improve the extension, it sends anonymous usage statistics to Datadog, a monitoring service operated by the developer. You can turn this off at any time in the extension's Settings ("Anonymous usage statistics").

What is sent:

- Which features are used (for example: a bookmark was saved, a folder was created, the poe.ninja / Path of Building import was run) and counts (number of items imported, number of mods matched).
- Error codes when something fails (for example: "network", "catalog-unavailable").
- Game modifier text that the import could not match to a trade filter. This is public game data, not your data.
- Extension version and a random install identifier that is not linked to your account or identity.

What is never sent:

- Your Path of Exile account, character names, session, or anything from your stash.
- Your search queries, bookmarks, folder names, or the contents of the pages you visit.
- Browsing history or URLs.

No data is sold or shared with third parties beyond the monitoring service used to store these statistics.
